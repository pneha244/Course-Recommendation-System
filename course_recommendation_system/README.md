# Course Recommendation System

This project implements a content-based and hybrid course recommendation system with a Streamlit UI.

Quick start

1. Create and activate a virtual environment.
2. Install dependencies:

```
pip install -r course_recommendation_system/requirements.txt
```

3. Run the app:

```
streamlit run "Project 17 - Course Recommendation System/course_recommendation_system/app.py"
```

Notes
- Place sample CSV datasets (e.g. `coursea_data.csv`, `udemy_courses.csv`) in the project root or the package folder; the loader will search nearby directories.
- Exports recommendations as CSV from the UI.
